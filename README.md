# HomeLab

A bare-metal Kubernetes homelab built from scratch as a learning project, managed entirely through GitOps with Flux CD.

> This repo is a learning journal as much as it is an infrastructure repo. Every decision, mistake, and fix is documented.

---

## Repository Structure

```
HomeLab/
├── clusters/
│   └── homelab/            # Flux CD entry point — bootstrapped into the cluster
│       └── flux-system/    # Auto-generated by Flux bootstrap
├── infrastructure/
│   ├── controllers/        # Helm-managed cluster controllers (MetalLB, NGINX, CloudNativePG, monitoring)
│   └── config/             # Controller configuration (IP pools, secrets, monitoring namespace)
├── apps/
│   ├── base/               # Shared base resources
│   └── homelab/            # App deployments
│       ├── nginx/          # Test NGINX deployment
│       ├── whoop/          # Whoop health data pipeline
│       ├── linkding/       # Linkding bookmark manager
│       ├── grafana/        # Grafana ingress
│       └── alertmanager/   # Alertmanager ingress
└── docs/
    ├── journal.md          # Full learning journal — phases, problems, and solutions
    └── architecture.md     # Cluster architecture and stack overview
```

---

## Stack

| Layer | Technology |
|-------|-----------|
| Hardware | 2x bare-metal laptops (HP ProBook 4520s + Asus X555L) |
| OS | Ubuntu Server 24.04.3 LTS |
| Orchestration | K3s |
| GitOps | Flux CD v2 |
| Load Balancer | MetalLB |
| Ingress | NGINX Ingress Controller (NGINX Inc) |
| Database | CloudNativePG (PostgreSQL operator) |
| TLS | cert-manager + Let's Encrypt (Cloudflare DNS-01) |
| Secret Management | SOPS + age encryption |
| Secret Sync | reflector (cross-namespace mirroring) |
| Public Exposure | Cloudflare Tunnel (cloudflared) |
| Monitoring | kube-prometheus-stack (Prometheus + Grafana + Alertmanager) |
